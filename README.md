# For Miss Sara

An interactive flower card: a greeting, a bouquet of light pink roses over a sunflower field at sunset, a sweet note, and a cartoon of Sara & Howard.

## Put it online with GitHub Pages
1. Create a new repository on GitHub (e.g. `for-sara`).
2. Upload `index.html` (and this README) to the repository.
3. Go to **Settings → Pages**, set **Source** to "Deploy from a branch", pick `main` and `/ (root)`, then **Save**.
4. After a minute your card is live at `https://<your-username>.github.io/for-sara/`.

Navigate with the Next/Back buttons, the arrow keys, or by swiping on a phone.
